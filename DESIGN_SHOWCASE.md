## 🎬 Animations

### 1. Fade In
```
Start:  Opacity 0, Transform translateY(10px)
End:    Opacity 1, Transform translateY(0)
Speed:  0.5s ease-in-out
Used:   Cards, sections, content
```

### 2. Slide In Down
```
Start:  Opacity 0, Transform translateY(-20px)
End:    Opacity 1, Transform translateY(0)
Speed:  0.5s ease-in-out
Used:   Navbar, modals, alerts
```

### 3. Slide In Up
```
Start:  Opacity 0, Transform translateY(20px)
End:    Opacity 1, Transform translateY(0)
Speed:  0.5s ease-in-out
Used:   Modals, panels, popups
```

### 4. Pulse Glow
```
Animation: Expanding shadow rings
Speed:    2s infinite
Used:     Badge pulses, notifications
```

### 5. Gradient Shift
```
Animation: Background gradient movement
Speed:    8s infinite
Used:     Progress bars, animated elements
```

## ♿ Accessibility Features

### Focus States
```
Default state:    Normal styling
Focus state:      2px outline #0284c7 with 2px offset
                  Visible when tabbing
                  Clear, high contrast

Keyboard nav:     Tab → Tab → Tab (navigate)
                  Enter/Space (activate)
```

### Color Contrast
```
All text:         WCAG AA compliant
Normal text:      4.5:1 minimum ratio
Large text:       3:1 minimum ratio
Buttons:          4.5:1 minimum ratio
```

### Touch Targets
```
All interactive:  44×44px minimum
Buttons:          48×48px typical
Links:            44×44px
Form inputs:      44×44px
```
